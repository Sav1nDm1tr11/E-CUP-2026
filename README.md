## EDA

### `00_EDA.ipynb`

Базовый анализ исходных данных без фильтрации:

- размер, типы и описание признаков;
- `describe`, пропуски и полные дубликаты;
- распределения всех признаков с типом и числом уникальных значений;
- динамика числа наблюдений и активных пользователей по датам;
- корреляционная матрица;
- boxplot для всех признаков;
- pairplot для основных признаков;
- PCA: explained variance и направления исходных признаков.

### `01_EDA_no_outliers.ipynb`

Тот же анализ после небольшой очистки тяжелых хвостов.

Для числовых не категориальных признаков вычисляются 1% и 99% квантили; удаляются строки, в которых хотя бы один из этих признаков выходит за соответствующий диапазон.

Размер выборки уменьшается:

```text
30 631 006 -> 29 358 420 строк
```

То есть удаляется около **4.2%** наблюдений.

Это именно сравнительный вариант EDA, а не окончательное решение по preprocessing. Точки за усами boxplot могут оставаться: после фильтрации boxplot заново вычисляет границы по правилу `1.5 * IQR`.

## Основные выводы

- Данные содержат **30.6 млн строк, 18 колонок и 250 тыс. пользователей** за период с `2025-01-01` по `2026-02-13`.
- Явных пропусков и полных дубликатов нет.
- `search`, `cat` и `has_*` -- бинарные признаки.
- Счетчики переходов и GMV сильно разрежены, имеют много нулей и тяжелые правые хвосты. Для дальнейшего анализа стоит проверить влияние `log1p`.
- По временным графикам виден общий восходящий тренд активности; визуально просматривается недельная периодичность _(проверьте)_.
- Сильные корреляции наблюдаются между `search_to_cart` и `to_cart`, `search_to_ord` и `to_ord`, `gmv_search` и `gmv`. Часть признаков может оказаться избыточной.
- После удаления крайних квантилей распределения становятся компактнее, но сильная асимметрия части признаков сохраняется.
- В исходных данных PC1 объясняет около **29.5%**, PC2 -- **16.2%** дисперсии; около 95% дисперсии набирается примерно к 11-й компоненте.
- После фильтрации PC1 объясняет около **32.5%**, PC2 -- **18.2%**; около 95% дисперсии набирается уже примерно к 9-й компоненте.
